## Setting Up This Repo(Windows Only):

<p style="font-size: 16px;">When setting up this Django Project, you'll need Python Version 3.x.x and up. Once python is installed to your PC, find the downloaded zip file you'll get from here, by clicking the green "Code" button and finding "Download ZIP". First, extract it, and get rid of the zip file. Next, open the folder until you're at the root directory(/Django_Project_main/Django_Project_main). Next, right click on any blank space inside this folder, and click "Open In Terminal". This should open Windows Powershell, and the directory will point to the project. After that, type in "python3 -m venv djvenv" and hit enter. This will create a python virtual environment in order to host the server. Once this is done, before activating the virtual environment, you need to allow script execution by typing "Set-ExecutionPolicy -ExecutionPolicy Bypass Process" and hitting enter. Once it's allowed, type ".\djvenv\Scripts\Activate.ps1" and hit enter. You can tell it's on by looking for the green (djvenv) at the left side. Furthermore, you need to install base Django by typing "python3 -m pip install django" and hitting enter. Next, you need to install the requirements on the project. Type in "pip install -r requirements.txt" and hit enter. At this point, you would think were done, but no. Before the final step of starting the server, you need to migrate all of this project's changes by typing "python manage.py migrate" and hitting enter. Finally, to start the server, type "python manage.py runserver" and hit enter. This should make it all functional, except you wont have any students or projects. With that, you need to go into the Students tab, create a student, and only after creating a student can you create a portfolio, and projects inside that portfolio.</p>

## Turning Off Server & Exiting Virtual Environment:

<p style="font-size: 16px;">For this, all you have to do is go back to Windows Powershell, hit Control + C while in the console, and it should bring back the root directory with the green (djvenv) indicator at the far left. Then, type "deactivate" and hit enter. That is all.</p>
