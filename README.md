## Setting Up This Repo(Windows Only):

<p style="font-size: 16px;">When setting up this Django Project, you'll need Python Version 3.x.x and up. Once python is installed to your PC, find the downloaded zip file you'll get from here, by clicking the green "Code" button and finding "Download ZIP". First, extract it, and get rid of the zip file. Next, open the folder until you're at the root directory(/Django_Project_main/Django_Project_main). Next, right click on any blank space inside this folder, and click "Open In Terminal". This should open Windows Powershell, and the directory will point to the project. After that, type in "python3 -m venv djvenv" and hit enter. This will create a python virtual environment in order to host the server. Before doing anything, you need to install base Django by typing "pip install django" and hitting enter. Next, you need to install the requirements on the project. Type in "pip install -r requirements.txt" and hit enter. If it fails to build, try using "python.exe -m pip install --upgrade pip". Once this is done, before activating the virtual environment, you need to allow script execution by typing "Set-ExecutionPolicy -ExecutionPolicy Bypass Process" and hitting enter. Once it's allowed, type ".\djvenv\Scripts\Activate.ps1" and hit enter. Finally, to start the server, type "python manage.py runserver" and hit enter. This should make it all functional, except you wont have any students or projects. With that, you need to go into the Students tab, create a student, and only after creating a student can you create a portfolio, and projects inside that portfolio.</p>
